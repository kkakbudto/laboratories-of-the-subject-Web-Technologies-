Сгенерировать UUID

Отправляет запрос на маршрут GET /api/uuid?count=N (от 1 до 10, по умолчанию 1). В офлайн-режиме приложение остаётся доступным и может генерировать UUID локально в браузере.

    Проверка маршрутов API и валидации

    Быстрые кнопки для демонстрации ответов сервера и обработки ошибок (HTTP 200 и 400). 

    Нажмите любую кнопку выше или «Сгенерировать», чтобы увидеть ответ сервера.
    Node.js · Express · crypto.randomUUID() · PWA (manifest.json + Service Worker)
