Персональная HTML-страница «О себе».

## Автор
- ФИО: Чумакова Дарья

## Описание
Учебный проект - персональная веб-страница с информацией о навыках, 
проектах и формой обратной связи. Выполнена в бирюзово-белой цветовой гамме.

## Структура проекта
- `about_me.html` - основная страница
- `images/` - изображения

## Как открыть
1. Скачайте папку с проектом.
2. Откройте файл `about_me.html` в любом браузере 
   (двойной клик или правый клик → «Открыть с помощью»).

## Технологии
- HTML5

## Что использовано
- Семантические теги: `<header>`, `<main>`, `<section>`, `<aside>`, `<footer>`
- Списки: `<ul>`, `<ol>`
- Форма: `<input>`, `<textarea>`, `<button>`
- Изображения: `<img>`
