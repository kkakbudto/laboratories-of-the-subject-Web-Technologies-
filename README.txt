Описание

Учебный проект - серверное приложение на Node.js и Express с базой данных SQLite для хранения и обработки списка покупок (таблица shopping_items), а также веб-интерфейсом для работы через браузер. Страница оформлена в палитре #e5dec2 (основной фон), #142841 (шапка и основной текст), #490b1a (акцентные кнопки и высокий приоритет) и #798da6 (второстепенные элементы) со шрифтом Montserrat.

В этой версии реализованы:

База данных SQLite: Автоматическое создание БД и таблицы shopping_items с полями id, item_name, priority (LOW, MEDIUM, HIGH), purchased (BOOLEAN) и updated_at при первом запуске.

Модульные CRUD-функции: Отдельный модуль для чтения всех записей с фильтрацией и сортировкой, чтения по ID, создания новой покупки, переключения статуса purchased с обновлением updated_at и удаления записи.

REST-маршруты Express:
- GET /api/shopping - получение списка покупок с сортировкой от HIGH к MEDIUM и LOW
- GET /api/shopping?priority=HIGH - фильтрация покупок по приоритету (неизвестный приоритет возвращает ошибку 400)
- GET /api/shopping/:id - получение одной записи по ID (некорректный ID - 400, не найдено - 404)
- POST /api/shopping - добавление новой покупки с валидацией item_name и priority (ошибка валидации - 400, успех - 201)
- PATCH /api/shopping/:id - переключение статуса purchased и обновление поля updated_at (не найдено - 404)
- DELETE /api/shopping/:id - удаление покупки по ID (не найдено - 404)

Веб-интерфейс: Страница на корневом маршруте /, позволяющая добавлять покупки, фильтровать список по приоритету, отмечать купленные товары и удалять записи прямо в браузере.

Структура проекта

package.json - настройки проекта, зависимости и команды запуска
src/server.js - точка входа, запуск Express-сервера (порт по умолчанию 8080)
src/app.js - настройка Express-приложения, статики и обработки ошибок
src/db/database.js - подключение к SQLite и создание таблицы shopping_items
src/db/seed.js - заполнение базы данных 15 примерами покупок
src/crud/shoppingCrud.js - модульные CRUD-функции для работы с БД
src/routes/shoppingRoutes.js - маршруты /api/shopping и валидация входных данных
public/index.html - веб-интерфейс списка покупок
data/shopping.db - файл базы данных SQLite (создаётся автоматически при запуске)
README.txt - описание проекта

Как запустить

Откройте папку с проектом в терминале (PowerShell).
Установите зависимости командой: npm install
Запустите сервер командой: npm start
Для заполнения базы 15 примерами выполните: npm run seed
Откройте в браузере адрес: http://localhost:8080
При необходимости порт можно изменить через переменную окружения PORT (например, $env:PORT=3000; npm start).
