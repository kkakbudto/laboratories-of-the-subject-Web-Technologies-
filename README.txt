## Описание

Учебный проект - персональная веб-страница с информацией о навыках,
проектах и формой обратной связи. Оформлена в бирюзово-белой цветовой гамме
(основной - бирюзовый, акцент - белый).

Реализованы:
- Три способа подключения стилей (внешний, inline, внутренний `<style>`)
- CSS-переменные в `:root` для цветов и шрифтов
- Позиционирование: `static`, `relative`, `absolute`
- Псевдоклассы: `:hover`, `:active`, `:focus`, `:visited`
- Контрастность текста ≥ 4.5:1
- Переключение тёмной темы через CSS-переменные и JS
- Переключение языка: цветная рамка полей ввода по флагу языка

## Структура проекта
├── about_me.html - основная страница
├── style.css - внешние стили
├── js.js - скрипт (тема, язык, курсор)
├── README.md - описание проекта
└── images/ - изображения

## Как открыть

1. Скачайте папку с проектом.
2. Откройте файл `about_me.html` в любом браузере

## Технологии

- **HTML5**
- **CSS3** - переменные, Flexbox, позиционирование, псевдоклассы, градиенты
- **JavaScript** - переключение классов на `<body>`
