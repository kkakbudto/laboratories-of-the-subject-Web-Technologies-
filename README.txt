Описание

Учебный проект - персональная веб-страница с информацией о навыках, проектах, формой обратной связи и интерактивными элементами. Оформлена в бирюзово-белой цветовой гамме (основной - бирюзовый, акцент - белый) с соблюдением контрастности текста ≥ 4.5:1.

В этой версии реализованы:

Flexbox: Горизонтальное адаптивное навигационное меню и карточки в блоке «Изучаемые языки».

CSS Grid: Двумерная галерея в секции «Фраза недели» (3 колонки на ПК, 2 на планшетах, 1 на мобильных).

Адаптивность: Медиа-запросы для корректного отображения на экранах планшетов (до 1024px) и мобильных телефонов (до 600px). Горизонтальная прокрутка полностью исключена.

Интерактивность: Переключение тёмной/светлой темы, смена языка (цветная рамка полей ввода по флагу), кастомный курсор и воспроизведение аудио при клике на иконку.

Структура проекта

├── index.html - основная страница (HTML5)
├── style.css - стили (внешние, переменные, Flexbox, Grid, адаптивность)
├── js.js - скрипт (тема, язык, курсор, аудио, кнопка "наверх")
├── README.md - описание проекта
├── images/ - папка с изображениями и GIF-анимациями
└── audio/ - папка с аудиофайлами для произношения фраз

Технологии

HTML5 - семантическая разметка (<main>, <section>, <aside>, <article>, <nav>).

CSS3 - CSS Grid, Flexbox, Media Queries (адаптивный дизайн), CSS-переменные, позиционирование, псевдоклассы, градиенты, плавные переходы.

JavaScript - логика воспроизведения аудио, переключение классов для смены темы и языковых стилей, отслеживание скролла.
