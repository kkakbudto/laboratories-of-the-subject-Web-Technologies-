Описание

Учебный проект - персональная веб-страница с информацией о навыках, проектах, формой обратной связи, интерактивным словарем и мультимедийными элементами. Оформлена в бирюзово-белой цветовой гамме (основной - бирюзовый, акцент - белый) с соблюдением контрастности текста ≥ 4.5:1.

В этой версии реализованы:

Flexbox: Горизонтальное адаптивное навигационное меню, карточки в блоке «Изучаемые языки» и панель кнопок управления словарем.

CSS Grid: Двумерная галерея в секции «Фраза недели» (3 колонки на ПК, 2 на планшетах, 1 на мобильных).

Адаптивность: Медиа-запросы для корректного отображения на экранах планшетов (до 1024px) и мобильных телефонов (до 600px). Горизонтальная прокрутка полностью исключена.

Интерактивность: Переключение тёмной/светлой темы, смена языка (цветная рамка полей ввода по флагу), кастомный курсор, воспроизведение аудио при клике на иконку и кнопка возврата наверх.

JavaScript (Лабораторная 4): Скрипт для расчета статистики выученных слов (использование массивов, циклов, функций, alert и console.log).

DOM и localStorage (Лабораторная 5): Интерактивная таблица «Мой словарь» с добавлением новых слов и переводов, удалением отдельных строк, полной очисткой списка и скрытием/показом блока. Реализована проверка существования элементов перед манипуляциями (обработка ошибок), а также сохранение добавленных слов и выбранной темы в localStorage с восстановлением при перезагрузке страницы.

Структура проекта

index.html - основная страница (HTML5)
style.css - стили (внешние, CSS-переменные, Flexbox, Grid, стили таблицы словаря, адаптивность)
js.js - основной скрипт (тема, язык, курсор, аудио, кнопка "наверх", логика словаря и localStorage)
script.js - скрипт статистики слов (массивы, циклы, функции)
README.txt - описание проекта
images/ - папка с изображениями и GIF-анимациями
audio/ - папка с аудиофайлами для произношения фраз

Как открыть

Скачайте папку с проектом.

Или можно просмотреть по ссылке: https://kkakbudto.github.io/

Технологии

HTML5 - семантическая разметка (header, nav, main, section, aside, footer, table).

CSS3 - CSS Grid, Flexbox, Media Queries (адаптивный дизайн), CSS-переменные, позиционирование, псевдоклассы, градиенты, плавные переходы.

JavaScript (DOM API и Web Storage) - поиск элементов (getElementById, querySelector, querySelectorAll), динамическое создание и удаление узлов (createElement, appendChild, remove), управление классами и атрибутами, обработка ошибок и сохранение состояния в localStorage.
